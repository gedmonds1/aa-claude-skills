# Curricular Complexity Analysis

Analyze curriculum structures to identify barriers to student success and timely degree completion.

## Core Metrics

| Metric | Definition | Threshold |
|--------|------------|-----------|
| **Blocking Factor** | Courses blocked until this course is completed | >10 = bottleneck |
| **Delay Factor** | Longest prerequisite chain including this course | >6 = deep dependency |
| **Program Complexity** | Sum of (blocking + delay) for all courses | See benchmarks below |

## Complexity Benchmarks by Field

| Field | Typical Range | Notes |
|-------|---------------|-------|
| Business | ~170 | Low variance |
| Humanities/Social Sciences | 150-220 | Very flexible |
| Natural Sciences | 250-300 | Varies by discipline |
| Engineering | 325-450 | Highest; varies by sub-discipline |

**Interpretation**: <200 = low, 200-350 = moderate, 350-500 = high, >500 = intervention required

## Analysis Workflow

### Step 1: Baseline Assessment
1. Calculate program complexity score (sum of blocking + delay for all courses)
2. Identify bottleneck courses (blocking factor >10)
3. Map longest prerequisite chains
4. Compare to discipline benchmarks

### Step 2: Diagnose Issues
Select based on user concern:

| Concern | Analysis Focus |
|---------|---------------|
| Low graduation rates | Bottlenecks + DFW rates + margin for error |
| Retention problems | First-year complexity concentration |
| Equity gaps | Pathways for varying preparation levels |
| Peer comparison | Box plot positioning within discipline |

### Step 3: Identify Interventions

| Intervention | Typical Impact | Difficulty |
|-------------|---------------|------------|
| Prerequisite → co-requisite | 15-25% reduction | Low-Medium |
| Remove unnecessary prerequisites | 10-20% reduction | Low |
| Reduce credits (128→120) | 5-15% reduction | Medium |
| Create alternative pathways | 20-30% reduction | High |

### Step 4: Model Scenarios
Before recommending changes:
1. Calculate current complexity
2. Model complexity under each intervention
3. Compare impact-to-effort ratio
4. Prioritize quick wins (co-requisites, prerequisite removal)

### Step 5: Communicate Findings
Tailor to audience:
- **Leadership**: Executive summary, peer comparison, top 3-5 concerns, recommendations
- **Faculty committees**: Visualizations, peer data, frame as student success (not criticism)
- **Institutional research**: Full quantitative analysis, methodology documentation

## Critical Principles

**Compare within disciplines**: Engineering vs. engineering, not engineering vs. business

**Complexity ≠ rigor**: High-performing institutions often have low-complexity programs

**Verify accreditation claims**: Most prerequisite chains exceed actual requirements

**Frame as equity issue**: High complexity disproportionately affects first-gen, Pell-eligible, and underrepresented students

**Partner with faculty**: Present data to reveal structure, not criticize content decisions

## Quick Analysis Sequences

**5-Minute Assessment**: Complexity score → field comparison → top 3 bottlenecks → recommendation

**30-Minute Assessment**: Baseline → peer box plot → bottlenecks → co-requisite opportunities → brief summary

**Comprehensive Review**: Full baseline → multi-institution comparison → prerequisite mapping → all interventions → scenario modeling → executive summary + faculty brief
