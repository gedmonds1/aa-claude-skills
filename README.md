# AA Claude Skills

Custom Claude skill library developed by the Office of Academic Affairs 
at Syracuse University.

## Available Skills

- **aa-syllabus** — Create SU course syllabi following Academic Affairs requirements
- **curriculum-extractor** — Extract and analyze course data from SU catalog pages
- **qualtrics-qsf** — Generate Qualtrics survey files for import into SU's tenant
- **senate-syllabus-review** — Review syllabi for SCCI/Senate compliance

## How to Install

Download any `.skill` file and install it through Claude's Skills interface.
